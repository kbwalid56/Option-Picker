# 🎯 Option Picker

**Can't decide? Let fate choose!**

Option Picker is a simple desktop application built with **Node.js and Electron** that helps users make decisions when they are confused between multiple choices.

Simply enter your options, spin the virtual bottle, and let the app randomly select one for you!

## ✨ Features

- ➕ Add multiple options.
- ❌ Remove individual options.
- 🍾 Interactive bottle spinning animation.
- 🎯 Randomly select a winner.
- 💜 Modern dark-themed user interface.
- 🔄 Spin again whenever you want.
- 🧹 Reset all options.

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- Node.js
- Electron.js

## 🎮 How to Use

1. Open the application.
2. Enter your choices in the input field.
3. Click **Add** to add each option.
4. Add at least two options.
5. Click **Spin the Bottle**.
6. Wait for the bottle to stop.
7. See which option gets selected!

## 🎯 Project Goal

The goal of this project is to build a simple and interactive desktop application while learning the fundamentals of Electron, JavaScript, HTML, and CSS.
